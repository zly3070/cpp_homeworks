## 三、实验过程

### 1. 日期类的设计与实现（`date.h` 与 `date.cpp`）

#### （1）核心设计思路

`Date` 类采用 **绝对天数** 作为内部存储方式，将任意日期映射为从公元1年1月1日开始的整数天数，便于进行日期加减和比较运算。类中提供了：

- 构造函数：支持字符串解析（`"YYYY-MM-DD"`）和三整数参数
- 运算符重载：`+`、`-`、`++`、`--`、`<`、`==`、`!=` 等
- 成员函数：`getAbsDay()`、`getWeekDay()`、`isLeapYear()`、`print()` 等

#### （2）关键算法：绝对天数与年月日的互转

**`_ymd2i` 函数**：将年月日转换为绝对天数
```
绝对天数 = (年份-1)*365 + 闰年数 + 当前日期在当年的天数
```
其中闰年数 = `(y-1)/4 - (y-1)/100 + (y-1)/400`

**`_i2ymd` 函数**：将绝对天数转换为年月日
```
依次计算400年周期数、100年周期数、4年周期数、1年周期数
```

#### （3）运行结果验证

```text
Date d1("2026-05-28");
Date d2(2026, 5, 28);
cout << (d1 == d2) << endl;  // 输出 1
cout << d1.getWeekDay() << endl;  // 输出 Thu.
```

### 2. 统计天数（pr302A）

#### （1）程序代码

```cpp
void pr302A(istream& cin, ostream& cout) {
    map<string, int> sd;
    string name, status;
    Date d;
    while (cin >> name >> d >> status) {
        sd[name] = d.getAbsDay() + (status == "Out" ? 0 : 1 - sd[name]);
    }
    cout << "统计天数:\n";
    for (const auto& p : sd) {
        cout << left << setw(10) << p.first 
             << right << setw(5) << p.second << "\n";
    }
}
```

#### （2）运行结果

```text
统计天数:
Jone          7
Smith        40
```

#### （3）结果分析

利用 `map<string, int>` 自动按名字字典序排序的特性，分别记录每个人的进出日期。遇到 `Back` 时，`d.getAbsDay() + 1 - sd[name]` 计算出该次出差的实际天数（闭区间）。算法时间复杂度 O(n log n)。

### 4. 确定天数（pr302C）

#### （1）程序代码

```cpp
void pr302C(istream& cin, ostream& cout) {
    vector<NameNum> nd;
    Date curDay, d;
    cin >> curDay;
    string name;
    while (cin >> name >> d) {
        nd.push_back(NameNum(name, d - curDay));
    }
    sort(nd.begin(), nd.end());
    cout << "确定天数:\n";
    for (const auto& p : nd) {
        cout << p.name << " " << p.num << "\n";
    }
}
```

#### （2）运行结果

```text
确定天数:
NewYear 10
LaboursDay 130
```

#### （3）结果分析

与 `pr302B` 结构类似，区别在于存储的是节日与当前日期的差值（`d - curDay`）。通过 `sort` 按差值从小到大排序，实现“近者靠前”的要求。

### 6. 安排会议（pr302E）

#### （1）程序代码

```cpp
void pr302E(istream& cin, ostream& cout) {
    Date a, b, d, mD;
    int n, maxd = 0;
    cin >> a >> b >> n;
    cin.ignore();
    for (string s; getline(cin, s); a = d + 1) {
        istringstream sin(s);
        sin >> d;
        if (d - a > maxd) {
            maxd = d - a;
            mD = a;
        }
        if (sin >> d) continue;  // 若一行有两个日期，跳过第二个
    }
    if (b - a + 1 > maxd) {
        maxd = b - a + 1;
        mD = a;
    }
    d = mD + (maxd - n) / 2;
    cout << "安排会议:\n";
    d.print(cout, Date::MDYY);
    cout << "\n";
}
```

#### （2）运行结果

```text
安排会议:
11-08-2006
```

#### （3）结果分析

核心思路：找出**最长的未被安排的空闲区间**，然后在区间中央安排会议。

- 遍历每一行已安排的区间，计算当前区间开始与上一个区间结束之间的空闲长度
- 记录最大空闲区间的起点 `mD` 和长度 `maxd`
- 最后在最大空闲区间中计算中央位置：`mD + (maxd - n) / 2`
