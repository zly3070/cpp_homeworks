# 校友录管理系统

## 项目简介

基于 C++ 和 FTXUI 库开发的校友录管理系统，提供图形化终端界面（TUI），支持校友信息的增删改查和持久化存储。

## 功能特性

- 🖥️ **美观的 TUI 界面**：卡片式布局，焦点切换，实时搜索
- ➕ **添加校友**：通过表单录入完整的校友信息（10个字段）
- ✏️ **编辑校友**：选中卡片按 Enter 编辑，自动填充原数据
- 🗑️ **删除校友**：选中卡片按 d 键删除
- 🔍 **模糊搜索**：支持多关键词实时过滤，匹配任意字段
- 💾 **文件持久化**：数据自动保存到 data.txt，支持加载历史数据
- ⌨️ **快捷键操作**：Tab 切换焦点，↑↓ 选择，Enter 编辑，d 删除

## 项目结构

```
├── try.cpp          # TUI 主程序（入口文件）
```

## 依赖要求

- C++17 或更高版本
- FTXUI 库（5.0.0 或更高版本）
- CMake 3.11+（可选）

### 安装 FTXUI

```bash
# Ubuntu/Debian
sudo apt install libftxui-dev

# Arch Linux
sudo pacman -S ftxui

# 或从源码编译
git clone https://github.com/ArthurSonzogni/FTXUI.git
cd FTXUI
mkdir build && cd build
cmake ..
make
sudo make install
```

## 编译运行

### 方式一：使用 CMake（推荐）

```bash
mkdir build && cd build
cmake ..
make
./try
```

### 方式二：直接使用 g++

```bash
g++ -std=c++17 try.cpp -o try \
    -lftxui-screen -lftxui-dom -lftxui-component \
    -lpthread
./try
```

## 操作指南

### 界面焦点

- **Tab 键**：在工具栏和校友列表之间切换焦点
- 当前焦点区域会显示绿色高亮标题

### 校友列表操作（焦点在列表时）

| 按键  | 功能              |
| ----- | ----------------- |
| ↑/↓   | 选择上/下一个校友 |
| Enter | 编辑选中的校友    |
| d     | 删除选中的校友    |

### 工具栏操作（焦点在工具栏时）

| 按键/按钮 | 功能                   |
| --------- | ---------------------- |
| New 按钮  | 添加新校友             |
| 搜索框    | 输入关键词实时过滤列表 |

### 对话框操作

| 按键  | 功能             |
| ----- | ---------------- |
| Enter | 确认提交         |
| Esc   | 取消操作         |
| Tab   | 在输入框之间切换 |

## 数据存储

- 数据保存在程序运行目录下的 `data.txt` 文件中
- 每次增删改操作后自动保存
- 程序退出时自动保存
- 首次运行自动生成测试数据
